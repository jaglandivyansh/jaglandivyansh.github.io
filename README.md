# StudyLab
*Your Ultimate Competitive Exam Partner*

Live: [https://studylab-inky.vercel.app/](https://studylab-inky.vercel.app/)

## Overview
StudyLab is a comprehensive educational technology platform engineered to streamline competitive exam preparation for UPSC, SSC, RRB, and State PSC aspirants. It provides candidates with daily insights, progress tracking, and critical administrative updates in one seamless, cross-device Progressive Web App experience.

## Core Features
* **Bilingual Subject Library:** Structured, topic-wise notes and quizzes across all 13 subjects, with a Hindi/English toggle for every reading passage.
* **Adaptive Quiz & Flashcard Engine:** A classical quiz mode alongside a Shorts-style vertical swipe flashcard mode with spaced-repetition (SRS) rating, so revision fits into quick daily sessions.
* **RPG Skill Tree:** Prerequisite-locked, game-like progression through History and Polity topics.
* **Daily Current Affairs Digest:** A daily-updated feed of current affairs content, organized for fast scanning.
* **Real-Time Govt Job Updates:** RSS-powered tracking of the latest government job postings and deadline alerts, so candidates never miss an opportunity.
* **AI Doubt Solver:** An integrated AI assistant for on-demand explanations and doubt-clearing, proxied securely through a serverless backend.
* **Progress Analytics & Bookmarks:** Session history, readiness tracking, and saved content for focused revision.
* **Installable PWA:** Full offline-capable install experience on Android and iOS, with push notifications for daily updates.
* **Universal Compatibility:** A responsive architecture ensuring the interface adapts perfectly across desktop monitors, tablets, and mobile devices.

## Design Philosophy
The application features a modern, premium aesthetic. The UI prioritizes clean, solid design elements, distinct typography, and smooth, high-framerate motion graphics to create a distraction-free learning environment. Visual clarity is strictly maintained by avoiding glassmorphism or overly transparent effects, ensuring optimal readability across all sections.
